# dns_server

## Имеем
-  Парсинг Header, Question и Resource, формирование ответа
-  tcp и udp сервер на 53 порту
-  Конфиг `records.tsv`: домен и IPv4 через табуляцию
-  Поиск в конфиге, мапе-кэше с TTL и затем в `8.8.8.8`

## Запуск
```
make && sudo ./dns_server 
```
dns-сервер будет слушать 53 порт на localhost

Для доступа по внешнему IP ВМ укажи её сетевой адрес вторым аргументом:
```
sudo ./dns_server 10.101.0.10
```
